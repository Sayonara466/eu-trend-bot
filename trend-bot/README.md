# EU Trend Analyzer Bot

## Telegram бот для ежедневной аналитики набирающих популярность товаров и услуг в Европе

## Настройка

### 1. Создайте Telegram бота

1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя бота (например: `EU Trend Analyzer`)
4. Придумайте username (например: `eu_trend_analyzer_bot`)
5. BotFather выдаст вам **TOKEN** — скопируйте его

### 2. Запустите бота

```bash
# Установите зависимости
npm install

# Запустите бота
TELEGRAM_BOT_TOKEN="ваш_токен_сюда" npm start
```

### 3. Опции (переменные окружения)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | **Обязательный** |
| `ALLOWED_USERS` | ID пользователей через запятую (для ограничения доступа) | Все |
| `CRON_SCHEDULE` | Расписание автозапуска (cron формат) | `0 9 * * *` (09:00 MSK) |
| `ADMIN_CHAT_ID` | Chat ID для получения автозапуска | — |

### Пример запуска с ограничением доступа:

```bash
TELEGRAM_BOT_TOKEN="123456:ABC-DEF" \
ALLOWED_USERS="123456789,987654321" \
CRON_SCHEDULE="0 10 * * *" \
npm start
```

## Как работает

1. **Кнопка "Запустить аналитику"** — запускает поиск по 8+ запросам, обрабатывает сотни источников
2. **Кнопка "Выдать результаты"** — присылает топ-20+ трендов с ссылками на сайты
3. **Автозапуск** — каждый день в 09:00 MSK запускает анализ автоматически и присылает уведомление

## Результаты

Результаты сохраняются в `data/latest_results.json` и обновляются при каждом новом анализе.
