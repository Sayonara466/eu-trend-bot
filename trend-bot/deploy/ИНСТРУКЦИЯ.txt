# РАЗВЕРТЫВАНИЕ БОТА НА REPLIT.COM (С ТЕЛЕФОНА ЗА 5 МИНУТ)

## Быстрый старт:

### 1. Открой https://replit.com в браузере (с телефона тоже работает)
### 2. Зарегистрируйся или войди (через Google/проще всего)
### 3. Нажми "Create Repl" -> выбери "Node.js" -> назови "eu-trend-bot" -> Create
### 4. Удали все файлы что там есть
### 5. Создай 3 файла:

**Файл 1: .replit** (точка в начале важна!)
```
run = "node bot.js"
language = "nodejs"
```

**Файл 2: package.json**
```json
{
  "name": "eu-trend-bot",
  "version": "1.0.0",
  "type": "module",
  "scripts": { "start": "node bot.js" },
  "dependencies": {
    "node-telegram-bot-api": "^0.66.0",
    "node-cron": "^3.0.3"
  }
}
```

**Файл 3: bot.js**
(Вставь полное содержимое файла bot.js)

### 6. Открой вкладку "Shell" внизу и напиши:
```
npm install
```
### 7. Нажми кнопку "Run" (зелёная стрелка) наверху
### 8. В консоли увидишь "EU TREND BOT — DEPLOY VERSION" — бот работает!

## Готово! Теперь бот работает 24/7!

## Чтобы бот НЕ засыпал (бесплатно):
1. Зайди на https://uptimerobot.com
2. Создай монитор -> тип HTTP(s)
3. URL: вставь URL твоего Replit (появится после нажатия Run)
4. Интервал: каждые 5 минут
5. UptimeRobot будет пинговать бота и он не уснёт

## Альтернативы (если надо 100% без засыпания):
- **Render.com** — бесплатно, не засыпает. Create Web Service -> подключи GitHub
- **Railway.app** — бесплатно, 500 часов/месяц
- **VPS** (от $3/мес) — 100% надёжно
