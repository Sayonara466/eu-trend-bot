# 🇪🇺 EU Trend Bot — Инструкция по деплою на Replit

## 📱 Деплой с телефона за 10 минут

### Шаг 1. Перейдите на Replit
1. Откройте браузер на телефоне
2. Перейдите на **https://replit.com**
3. Зарегистрируйтесь или войдите (можно через Google / GitHub)

### Шаг 2. Создайте новый Repl
1. Нажмите кнопку **"Create Repl"**
2. В качестве шаблона выберите **"Node.js"**
3. Дайте название, например: `eu-trend-bot`
4. Нажмите **"Create Repl"**

### Шаг 3. Загрузите файлы
1. Удалите стандартные файлы (`index.js`, `package.json` и т.д.)
2. Создайте **3 файла** (нажмите кнопку "+" → "New file"):

   | Файл | Что вставить |
   |------|-------------|
   | `.replit` | Содержимое файла `.replit` |
   | `package.json` | Содержимое файла `package.json` |
   | `bot.js` | Содержимое файла `bot.js` |

> ⚠️ **Важно:** файл `.replit` начинается с точки! В Replit назовите файл именно `.replit`

### Шаг 4. Установите зависимости
1. Откройте вкладку **"Shell"** (консоль) внизу экрана
2. Введите команду:
   ```
   npm install
   ```
3. Дождитесь завершения установки (10-30 секунд)

### Шаг 5. Запустите бота
1. Нажмите кнопку **"Run"** ▶️ в верхней панели
2. В консоли должно появиться:
   ```
   ═══════════════════════════════════════════════
   🇪🇺  EU Trend Bot запущен!
   ═══════════════════════════════════════════════
   ```

### Шаг 6. Проверьте бота
1. Откройте Telegram
2. Найдите вашего бота
3. Нажмите **"Start"**
4. Попробуйте кнопки!

## ⏰ Как держать бота включённым 24/7

### Проблема
Бесплатный план Replit **засыпает** через 1 час неактивности.

### Решение 1: UptimeRobot (бесплатно)
1. Зарегистрируйтесь на **https://uptimerobot.com**
2. Создайте новый монитор
3. Тип: **HTTP(s)**
4. URL: URL вашего Replit-приложения (появится после деплоя)
5. Интервал: **каждые 5 минут**
6. UptimeRobot будет «пинговать» бота и не давать ему уснуть

### Решение 2: Replit Hacker Plan (~$7/мес)
- Платный план Replit — бот работает **24/7 без засыпания**
- Подходит для продакшена

### Решение 3: VPS (самый надёжный)
- Арендуйте дешёвый VPS (от $3-5/мес)
- Установите Node.js
- Запустите бота через `pm2`:
  ```
  npm install -g pm2
  pm2 start bot.js --name eu-trend-bot
  pm2 save
  pm2 startup
  ```

## ❓ Частые проблемы

**Q: Бот не запускается, ошибка в консоли**
A: Убедитесь, что вы выполнили `npm install` и все 3 файла созданы корректно.

**Q: Бот перестал отвечать через час**
A: Это нормально для бесплатного Replit. Настройте UptimeRobot (см. выше).

**Q: Кнопки не работают**
A: Попробуйте `/start` заново или перезапустите бота кнопкой "Run".

**Q: Аналитика ничего не находит**
A: DuckDuckGo может временно блокировать IP. Подождите и попробуйте снова.
